# Lite3 运动步态控制设计指标

> 本工程最终目标。步态为 trot；下列指标由开环关节 PD 实测标定，MPC/WBC 闭环版本需按同口径复测。调参过程见 [优化日志](05_优化日志.md)。

## 1. 坐标系与指令

- 机体系 $B$：$x$ 向前、$y$ 向左、$z$ 向上。
- 指令 $\mathbf{u}=[v_x,v_y,\omega_z]^T$：$v_x>0$ 前进，$v_y>0$ 左移，$\omega_z>0$ 左转（逆时针）。
- 正反向指标对称，按绝对值考核。

## 2. 速度区间

### 2.1 单轴区间（其余两轴为 0）

| 轴 | 区间 | 上限依据 |
| --- | --- | --- |
| $v_x$ | **0.10 – 0.60 m/s** | 实测 0.70 通过、0.75 开始跟踪振荡，取 0.60 |
| $v_y$ | **0.10 – 0.35 m/s** | 0.35 / 0.40 无航向漂移；0.30 与 0.45 以上出现 0.05–0.07 rad/s 左偏 |
| $\omega_z$ | **0.10 – 0.50 rad/s** | 实测到 0.70 仍稳定（未继续上探），取 0.50 |

### 2.2 组合约束

$$
\sqrt{v_x^2+v_y^2}\;+\;0.18\,\lvert \omega_z\rvert \;\le\; 0.67
$$

- 先按区间裁剪单轴（超过上限的指令直接被截到上限），再判断归一化约束；
- 归一化超限时三轴同比例缩比，运动方向不变；单轴与纯转向指令不会被缩比；
- 0.18 为转向折算系数（量级为足端前后偏移），把角速度换成等效平移速度；0.67 为工程上限，实测 $s\approx0.93$ 才翻倒。

### 2.3 组合工况

达标 = 线速度误差、偏航误差、两项逐周期峰峰值均 ≤ 0.05。

| 组合 | 名义指令 | $s$ | 实际下发 | 达标 |
| --- | --- | --- | --- | --- |
| 单轴 | 0.60 / 0.35 / 0.50 | ≤ 0.60 | 不缩比 | 3/3 轴 |
| $v_x+v_y$ | 0.60 / 0.35 | 0.70 | 0.58 / 0.34 | 2/4 |
| $v_x+\omega_z$ | 0.60 / 0.50 | 0.69 | 0.58 / 0.49 | 3–4/4 |
| $v_y+\omega_z$ | 0.35 / 0.50 | 0.44 | 0.35 / 0.50 | 1–2/4 |
| 三轴 | 0.60 / 0.35 / 0.50 | 0.78 | 0.51 / 0.30 / 0.43 | 4/4 |

> 以上组合均无翻倒、无力矩饱和，稳态最大侧倾 < 5°。剩余未达标项全部为偏航漂移/波动 0.05–0.08 rad/s，集中在 $v_x$ 与 $v_y$ 同时非零的斜向工况；开启仿真保真度 override 后由双稳态降为可复现的确定值，但仍略超阈值，属闭环航向任务（MPC/WBC）的验收项。
> 区间写法说明：逐次重复实验存在 1 项的判定跳变（值都在 0.050–0.056 区间），故取范围。

## 3. 分段步态参数

主运动方向按 $\max(\lvert v_x\rvert/0.60,\ \lvert v_y\rvert/0.35,\ \lvert \omega_z\rvert/0.50)$ 判定，再用该轴物理值查段；归一化分量并列时按 $x\to y\to z$ 优先取轴。

| 速度段 | 触发条件 $v_x$ / $v_y$ / $\omega_z$ | 周期 $T$ (s) | 占空比 $d$ | 抬腿 $H$ (m) | 步频 (Hz) |
| --- | --- | --- | --- | --- | --- |
| 低速 | < 0.20 / < 0.15 / < 0.20 | 1.20 | 0.72 | 0.07 | 0.83 |
| 中速 | 0.20–0.35 / 0.15–0.22 / 0.20–0.30 | 0.75 | 0.70 | 0.07 | 1.33 |
| 高速 | > 0.35 / > 0.22 / > 0.30 | 0.44 | 0.625 | 0.07 | 2.27 |

- 段间插值带宽：$v_x$ 0.10 m/s、$v_y$ 0.075 m/s、$\omega_z$ 0.10 rad/s；切换 $T$ 时保持相位连续。带宽较宽是因为减速时命令会连续穿过三个速度段，周期 0.44 → 0.75 → 1.20 逐级拉长，窄带宽会让足端行程 $vTd$ 在一帧内跳变（三轴急停实测冲击 13°）。
- 三个方向共用同一组 $T,d,H$；步幅在线生成 $\Delta p = T d\,(\mathbf{v}+\boldsymbol{\omega}\times\mathbf{p}_0)$，不单独设限。
- 最大步幅（各段按自身速度上界）：低速 0.173 m、中速 0.184 m、高速 0.165 m；三轴组合受 2.2 约束后最差 0.20 m。足端相对髖部的矢状距离不超过腿长的 75%，工作空间不是限制项。
- 停步为软停步：命令归零后不立即退出步态，等相位回到 $\theta\approx0$（四足同时支撑、足端正好在标称位）再退出，避免目标位跳变；减速斜坡单独放慢到 0.75 s⁻¹（加速仍为 1.5 s⁻¹）。

整定目标为**降步频、增步幅**（减少抬腿次数、降低功耗）。相对上一版（0.75/0.63/0.44，$H$=0.09/0.09/0.07）：

| 速度段 | 步频 | 步幅（段上界） | 关节机械功率 $\sum\lvert\tau\dot q\rvert$ |
| --- | --- | --- | --- |
| 低速 | 1.33 → 0.83 Hz（−38%） | 0.108 → 0.173 m（+60%） | 22.5 → 9.1 W（−60%） |
| 中速 | 1.59 → 1.33 Hz（−16%） | 0.154 → 0.184 m（+20%） | 35.1 → 21.5 W（−39%） |
| 高速 | 2.27 Hz（不变） | 0.165 m（不变） | — |

三段周期接近等比（$1.20 : 0.75 : 0.44 \approx 1.60 : 1.70$），使低速→中速→高速的过渡平缓；中速选 0.75 而不是更慢的 1.05，是因为后者会把中→高的周期比拉到 2.4 倍，而过渡冲击实测差距不足 1°（在噪声内），不值得为此多担中速段的功率与步幅波动。

高速段为何不能降频：三轴组合（0.51/0.30/0.43）的偏航波动 $\mathrm{p2p}_{\omega_z}$ 随步幅增长，$T\ge0.46$ 即越过 0.05 阈值；在相同步幅下降低占空比（0.46/0.63、0.50/0.58）同样失稳。因此高速段锁定 0.44/0.625。

基线标定条件（影响上述全部数值）：

- 标称足位按整机质心后移 13.3 mm（质心在髂中心后 7.2 mm，默认站立角落足中心在前 6.1 mm），前后腿负载均衡；
- 仿真开启执行器模型：关节电枢惯量 0.01 kg·m²、粘性阻尼 0.1 N·m·s/rad、足端接触 `condim=4`、扭转摩擦 0.03（官方 MJCF/URDF 均未提供，属模型简化）；
- 起步足端混合 0.8 s；以上参数均可用环境变量回退到官方原模型。

## 4. 验收标准

1. 稳态跟踪误差：线速度 ≤ 0.05 m/s，偏航角速度 ≤ 0.05 rad/s。
2. 稳态逐周期均值峰峰值 ≤ 0.05 m/s 或 ≤ 0.05 rad/s，无持续振荡。
3. 无翻倒（倾角 > 25° 或基座高度 < 0.15 m）；建议稳态倾角 < 15°。
4. 单轴全区间、三轴组合、以及跨速度段连续运行（`segments_3x3_20s`）必须全部达标；双轴斜向组合允许保留上述偏航残余，作为闭环验收项。
5. 关节力矩不长时间饱和，支撑足无持续滑移。
6. 段间切换平滑，无速度突变。

稳态窗口：跳过每个运动段前 2 s，取其后不少于 3 个完整步态周期。

## 5. 鲁棒性实测

全部在默认参数、平地（除坡面项）下无头运行，脚本见 `mpc_wbc/test/run_robustness.sh`。

| 扰动 | 做法 | 结果 |
| --- | --- | --- |
| 侧向推力 | 30 N × 0.15 s（±y，机身质心） | 峰值倾角 6.0° / 5.7°，0.50 / 0.66 s 恢复，残余航向 0.0° |
| 侧向推力（加严） | 45 N × 0.15 s | 峰值倾角 8.6°，0.57 s 恢复，残余航向 0.0° |
| 坡面 | 2°（上坡 0.15、上坡 0.30、下坡 0.30） | 3/3 达标，成本 0.105（平地同场景 0.106），最大倾角 1.6° |
| 速度阶跃 | 0.20 ↔ 0.50 m/s，每 3 s 切换，共 10 段 | 10/10 达标，成本 0.174，最大倾角 4.4°，最差 p2p 偏航 0.047 |
| 连续运行 | ±0.30 m/s 各 30 s 交替，共 300 s | 达标；航向漂移 **−0.03°**，倾角均值 0.37–0.44° |

- 45 N × 0.15 s 的横向冲量为 6.75 N·s，约等于机器人以 0.30 m/s 前进时动量的 1.9 倍，仍未翻倒且航向无残余；
- 2° 坡面对关节位置闭环几乎没有影响——开环步态只跟踪机身相对足端轨迹，不补偿坡度，因此上下坡的速度跟踪误差基本不变（最差 0.027 m/s，出现在下坡）；
- 5 分钟长跑没有出现随时间的性能劣化；倾角尖峰集中在 9 次**方向反转**，幅度 1.8–10.3°（均值 4.6°），反转经过低速段时周期被拉长所致，属已记录的瞬态，不是漂移。

## 6. 上机前复核清单

本基线是在 MuJoCo 中、用一组**拟合的**执行器/接触参数标定出来的。直接搬到实机前必须复核以下各项：

1. **执行器与接触参数需换成实测值**。关节电枢惯量 0.01 kg·m²、粘性阻尼 0.1 N·m·s/rad、足端扭转摩擦 0.03 目前是让仿真现象接近真实的拟合值（官方 MJCF/URDF 不提供这些量）。拿到减速比、转子惯量、脚垫硬度后，应替换 `SIM_JOINT_ARM / SIM_JOINT_DAMP / SIM_FOOT_CONDIM / SIM_FOOT_TORSION` 并重跑 §2.3 全工况，分段参数可能需要重新标定。
2. **功耗是代理指标**。§3 的功率为关节机械功率 $\sum\lvert\tau\dot q\rvert$ 与铜损代理 $\sum\tau^2$，不含电机 $K_t$、$R$ 与减速比，因此「−60%」应读作机械功耗下降，电池端收益需实测电流。
3. **未覆盖的扰动**：不平地形、低摩擦地面（$\mu<0.6$）、负载变化、侧向风、外力作用点不在机身质心的情况。
4. **未评估的硬件项**：关节温升与长时间力矩饱和、编码器噪声、1 kHz 控制回路在真实通信延迟下的表现。
5. **闭环交接**：双轴斜向偏航残余 0.05–0.07 rad/s 按 §4 第 4 条留给 MPC/WBC 闭环验收；闭环版本须按同一口径复测 §2–§5 全部工况。
