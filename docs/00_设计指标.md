# Lite3 运动控制设计指标

> 职责：定义运动包络、评价口径和验收要求。这里只列目标与判据；参数选择和实测结果见 [实验日志](05_优化日志.md)，完成情况见 [实施进度](04_Lite3_MPC_WBC实现步骤与里程碑.md)。

## 1. 对象与命令

对象为 Lite3 的平地 trot 运动，覆盖前进、后退、左右平移、双向原地转向、组合运动、停步和换向。

用户速度命令为机体系物理量 `u=[vx, vy, wz]`：x 向前、y 向左，正偏航为逆时针；正反向按绝对值使用相同要求。完整坐标和动力学约定见 [技术推导](09_MPC_WBC重新推导与基础契约.md)。

## 2. 运动包络

### 2.1 单轴工作区间

| 命令 | 工作区间 | 单位 |
| --- | --- | --- |
| 前后速度 `abs(vx)` | 0.10–0.60 | m/s |
| 左右速度 `abs(vy)` | 0.10–0.35 | m/s |
| 偏航角速度 `abs(wz)` | 0.10–0.50 | rad/s |

零命令用于静立和停步；起停斜坡经过工作区间下限以下的过程按瞬态评价，不作为独立稳态工况。超出单轴上限的目标先按对应上限裁剪。

### 2.2 组合约束

单轴裁剪后，要求

$$
s=\sqrt{v_x^2+v_y^2}+0.18|\omega_z|\le0.67.
$$

0.18 的单位为 m，s 的单位为 m/s。若超限，三轴同时乘以 `0.67/s`；此缩比步骤保持裁剪后命令的方向比例。

下面列出正向名义上限的限幅示例，各轴正负组合使用同一规则；表中不包含达标结果。

| 工况 | 名义 `vx/vy/wz` | 限幅后约值 |
| --- | --- | --- |
| 单轴 | 0.60 / 0 / 0；0 / 0.35 / 0；0 / 0 / 0.50 | 不缩比 |
| x+y | 0.60 / 0.35 / 0 | 0.58 / 0.34 / 0 |
| x+z | 0.60 / 0 / 0.50 | 0.58 / 0 / 0.49 |
| y+z | 0 / 0.35 / 0.50 | 不缩比 |
| 三轴 | 0.60 / 0.35 / 0.50 | 0.51 / 0.30 / 0.43 |

## 3. 评价口径

### 3.1 稳态窗口

每个运动段跳过前 2 s，其后至少保留 3 个完整步态周期。窗口不足时记为证据不足，不得判定达标。周期平均使用该段实际步态周期，不使用跨段统一的固定周期。

速度在机体系下评价：世界系平移速度按逐样本偏航角转换。目标采用包络限幅后、起停斜坡前的物理命令；起步、减速、停步、换向分别评价，不混入稳态均值。

| 指标 | 定义 | 上限 |
| --- | --- | --- |
| 平移速度误差 | 机体系平均水平速度与目标之差的二范数 | 0.05 m/s |
| 偏航角速度误差 | 平均偏航角速度与目标之差的绝对值 | 0.05 rad/s |
| 平移速度波动 | 用一个实际步态周期滑动平均后，x/y 速度峰峰值的较大者 | 0.05 m/s |
| 偏航角速度波动 | 同一滑动平均窗口下的偏航角速度峰峰值 | 0.05 rad/s |

### 3.2 姿态与执行质量

- 翻倒判据：`max(abs(roll), abs(pitch)) > 25°`，或基座高度 `<0.15 m`。不得只用控制器是否正常退出代替此判据。
- 建议稳态倾角 `<15°`；瞬态峰值另行报告。
- 关节力矩不得长期饱和，支撑足不得持续滑移。
- 起停和跨速度段切换应连续，报告速度、足端目标和实际力矩的变化；停步残余运动单独统计。

长期饱和、持续滑移、停步收敛时间及允许目标跳变量的数值门槛尚未冻结。报告必须披露对应比例、持续时间或曲线，不能仅凭稳态速度通过就宣称这些项目也已验收。

## 4. 必须覆盖的工况

| 验证组 | 覆盖要求 |
| --- | --- |
| 静立与接管 | 站立保持 20 s；位置控制到力控制的接管独立评价 |
| 单轴运动 | 低、中、高各覆盖前/后、左/右、顺/逆时针；每段 10 s，段间停 2 s |
| 组合运动 | 二轴、三轴的正反组合，命令满足第 2 节包络 |
| 跨段运行 | 各轴低/中/高连续切换，覆盖起步、减速和换向 |
| 侧向扰动 | ±30 N、持续 0.15 s；45 N 为加严工况，记录峰值倾角及恢复过程 |
| 坡面 | 2° 上坡/下坡，包含 0.15、0.30 m/s 前后向运动 |
| 速度阶跃 | 0.20↔0.50 m/s，每 3 s 切换，共 10 段；分别报告瞬态与可用稳态窗口 |
| 连续运行 | ±0.30 m/s 各 30 s 交替，总计 300 s；报告漂移和性能随时间的变化 |
| 重复性 | 固定模型、参数和场景至少重复 5 轮，报告均值、极值、失败次数 |

速度阶跃等短段若不满足第 3 节的稳态窗口要求，只能用于瞬态评价。扰动恢复判据及其他待冻结阈值由实施任务明确后补入本文。

## 5. 达标结论的边界

单轴、组合、跨段及扰动验证均应按对应工况报告，不能由其中一项替代其余项。开环历史中的双轴残余偏航属于未达标记录，不构成新闭环的指标豁免。

报告同时标明仿真模型、执行器/接触参数、初始条件、控制版本、重复次数与原始证据。仿真真值可用于独立评价，不得作为新闭环的在线控制输入。

仿真与真机分别验收。拟合参数、机械功率及铜损代理不能直接证明真机稳定性、电池功耗或硬件温升；真机准备任务见实施进度中的 N9。
