# Lite3 运动步态控制设计指标

> 本工程最终目标。步态为 trot；下列指标由开环关节 PD 实测标定，MPC/WBC 闭环版本需按同口径复测。调参过程见 [优化日志](05_优化日志.md)。

## 1. 坐标系与指令

- 机体系 $B$：$x$ 向前、$y$ 向左、$z$ 向上。
- 指令 $\mathbf{u}=[v_x,v_y,\omega_z]^T$：$v_x>0$ 前进，$v_y>0$ 左移，$\omega_z>0$ 左转（逆时针）。
- 正反向指标对称，按绝对值考核。

## 2. 速度区间

### 2.1 单轴区间（其余两轴为 0）

| 轴 | 区间 | 上限依据 |
| --- | --- | --- |
| $v_x$ | **0.10 – 0.60 m/s** | 实测 0.70 通过、0.75 开始跟踪振荡，取 0.60 |
| $v_y$ | **0.10 – 0.50 m/s** | 闭环双向 0.30→0.50 全档达标（倾角 ≤7.6°，0.50 处仅 6.4°、误差 0.027）；0.60 仍可用、0.70 跟踪到阈值、0.80 倾角 >10°（见 §2.4） |
| $\omega_z$ | **0.10 – 1.00 rad/s** | 闭环双向 0.30→1.00 全档达标（倾角 ≤3.3°、误差 ≤0.005 rad/s）；1.0 rad/s 为**稳定上限**，1.2–1.5 仍可用，≥2.5 开始姿态失稳（见 §2.4） |

### 2.2 组合约束（最终：只有一条线性归一化）

$$
\sqrt{v_x^2+v_y^2}\;+\;0.18\,\lvert \omega_z\rvert \;\le\; 0.67
\qquad\text{（超限时三轴同比缩比，方向不变）}
$$

- 单轴与纯转向都不会被缩比（$v_x$0.60、$v_y$0.50、$\omega_z$1.00 单独都满足）；
- 0.18 是转向折算系数（量级 = 足端切向速度 $\omega r\approx0.22$ m/s）；
- 0.67 是工程上限：实测不加任何约束时 $s=0.961$ 会 46.6° 翻车，取 0.67 留 30% 余量；
- 代码：`MpcWbcControllerParams::combo_max` / `combo_wz_ratio`（`S8_COMBO_MAX` / `S8_COMBO_WZ`）。

#### 2.2.1 一次测量伪影的更正（2026-11-01，重要）

曾经从 `analyze_axis_sweep.py` 的统计里拟合出「转向-平移竞争」项
$\Delta v\approx1.7\,v_{xy}\omega_z^2$，并据此加了一道
$v_{xy}\le0.05/(1.7\omega_z^2)$ 的守卫。**后来证明那是分析脚本的测量伪影**：

脚本把整段世界系速度用「该段平均偏航」只旋转一次，而原地转向时机身一直在转
（$\omega_z$0.5 × 8 s = 4 rad），段内样本方向跨度极大，取均值会被系统性压小，
**转得越快压得越厉害** —— 正好伪造出一条 $\propto\omega_z^2$ 的“损失”。
改成**逐帧**用该帧偏航旋转后，同一份 `sim.csv`：

| 工况 | 旧口径（平均偏航一次） | 逐帧口径（正确） |
| --- | --- | --- |
| $v_x$0.45 + $\omega_z$0.50 | 0.255（“损失 0.195”） | **0.499（无损失）** |
| $v_x$0.60 + $\omega_z$0.50 | 0.222（“损失 0.378”） | **0.640（偏快）** |
| $v_y$0.50 + $\omega_z$0.50 | 0.155（“损失 0.345”） | **0.498（无损失）** |
| 三轴 (0.60,0.50,1.00) | “平移≈0” | **0.497 / 0.306** |

结论：**转向并不抢平移的摩擦预算**，两者可以同时用。竞争项已默认关闭
（`combo_turn_loss=0`）。分析脚本已改为逐帧口径。

原指标 $\omega_z=0.50$ 由开环关节 PD 标定。换成 MPC+WBC 闭环后按同口径复测
（原地转向、8 s 段长、正反各 4 档、共 7 次独立重复），结果**不随速度单调**：

| 0.25 | 18.6 / 15.1 | 18.8 / 17.3 | ❌ 双向失稳 |
| 0.30 | 3.8 / 6.6 / 7.7 / 2.7 / 1.1 / 1.0 / 7.0 | 14.7 / 15.6 / 11.0 / 14.9 / 14.3 / 11.1 / 13.4 | ⚠️ 正向可用、反向不可用 |
| 0.35 | 17.1 / 16.8 / 17.0 / 16.8 / 14.8 | 19.0 / 16.0 / 17.7 / 16.0 | ❌ 双向失稳 |
| 0.40 | 3.1 / 2.1 / 3.2 / 3.0 / 3.7 | 7.8 / 10.5 / 13.5 / 12.5 / 8.9 | ⚠️ 正向 5/5 通过、反向临界 |

- 失稳形态是**段开始后 1–5 s 的 ~1 Hz 姿态极限环**（俯仰/横滚峰峰 29–30°），之后自行收敛到 0.1–0.3°；好段只有步频（2–4 Hz）成分、峰峰 3–4°。
- 已证伪的解法：MPC 20→50 Hz、固定中速段步态（同一 T/d 跑全部速度）、爬行步态、姿态权重/竖向环权重、支撑足位置与速度反馈、PD 叠加、`w_swing`、抬腿高度、**以及缓起步斜坡**（`cmd_tau` 0.25→0.9 s、`cmd_slew_w` 2.0→0.35 rad/s²：±0.30/0.35/0.40/0.45 → 7.0/14.8/3.7/16.1°，与突加命令同一分布）。
- 结论与后续：指标按闭环下调为 0.15 rad/s（0.30 仅作条件上限，且要求只考核正向稳态）；要恢复到 0.50 必须先抑制这个 1 Hz 机身模态（方向：支撑约束升级到位置级、或给姿态环加显式阻尼/前馈），而不是继续调速度包线与步态参数。

### 2.6 分级上限：单轴 / 双轴 / 三轴

不需要按轴数写三套判断——上限用**分量形式**写，轴数自动退化：

1. **单轴钳位**：$\lvert v_x\rvert\le0.60$、$\lvert v_y\rvert\le0.50$、$\lvert\omega_z\rvert\le1.00$
2. **组合归一化**：$v_{xy}+0.18\lvert\omega_z\rvert\le0.67$

**单轴**（其余为 0）：$v_x$ 0.60 m/s、$v_y$ 0.50 m/s、$\omega_z$ 1.00 rad/s。

**双轴**：

| 轴对 | 上限 |
| --- | --- |
| $v_x+v_y$ | $\sqrt{v_x^2+v_y^2}\le0.67$（再受单轴钳位）→ (0.60, 0.30) 或 (0.51, 0.43) |
| $v_x+\omega_z$ | $v_x\le\min\bigl(0.60,\ 0.67-0.18\lvert\omega_z\rvert\bigr)$ → $\omega_z$0.2→0.60；0.5→0.58；1.0→0.49 |
| $v_y+\omega_z$ | $v_y\le\min\bigl(0.50,\ 0.67-0.18\lvert\omega_z\rvert\bigr)$ → $\omega_z$0.2→0.50；0.5→0.50；1.0→0.49 |

**三轴**：$v_{xy}\le0.67-0.18\lvert\omega_z\rvert$（见 §2.5 表）。

实现：`cmd_max_vx/vy/wz`（单轴钳位）+ `combo_max`/`combo_wz_ratio`（组合归一化）。
env：`S8_CMDMAX_VX/VY/WZ`、`S8_COMBO_MAX`、`S8_COMBO_WZ`。
`combo_turn_gain`/`combo_turn_loss`/`combo_priority` 保留但默认关闭（见 §2.2.1）。

## 3. 分段步态参数

主运动方向按 $\max(\lvert v_x\rvert/0.60,\ \lvert v_y\rvert/0.35,\ \lvert \omega_z\rvert/0.50)$ 判定，再用该轴物理值查段；归一化分量并列时按 $x\to y\to z$ 优先取轴。

| 速度段 | 触发条件 $v_x$ / $v_y$ / $\omega_z$ | 周期 $T$ (s) | 占空比 $d$ | 抬腿 $H$ (m) | 步频 (Hz) |
| --- | --- | --- | --- | --- | --- |
| 低速 | < 0.20 / < 0.15 / < 0.20 | 1.20 | 0.72 | 0.07 | 0.83 |
| 中速 | 0.20–0.35 / 0.15–0.22 / 0.20–0.30 | 0.75 | 0.70 | 0.07 | 1.33 |
| 高速 | > 0.35 / > 0.22 / > 0.30 | 0.44 | 0.625 | 0.07 | 2.27 |

- 段间插值带宽：$v_x$ 0.10 m/s、$v_y$ 0.075 m/s、$\omega_z$ 0.10 rad/s；切换 $T$ 时保持相位连续。带宽较宽是因为减速时命令会连续穿过三个速度段，周期 0.44 → 0.75 → 1.20 逐级拉长，窄带宽会让足端行程 $vTd$ 在一帧内跳变（三轴急停实测冲击 13°）。
- 三个方向共用同一组 $T,d,H$；步幅在线生成 $\Delta p = T d\,(\mathbf{v}+\boldsymbol{\omega}\times\mathbf{p}_0)$，不单独设限。
- 最大步幅（各段按自身速度上界）：低速 0.173 m、中速 0.184 m、高速 0.165 m；三轴组合受 2.2 约束后最差 0.20 m。足端相对髖部的矢状距离不超过腿长的 75%，工作空间不是限制项。
- 停步为软停步：命令归零后不立即退出步态，等相位回到 $\theta\approx0$（四足同时支撑、足端正好在标称位）再退出，避免目标位跳变；减速斜坡单独放慢到 0.75 s⁻¹（加速仍为 1.5 s⁻¹）。

整定目标为**降步频、增步幅**（减少抬腿次数、降低功耗）。相对上一版（0.75/0.63/0.44，$H$=0.09/0.09/0.07）：

| 速度段 | 步频 | 步幅（段上界） | 关节机械功率 $\sum\lvert\tau\dot q\rvert$ |
| --- | --- | --- | --- |
| 低速 | 1.33 → 0.83 Hz（−38%） | 0.108 → 0.173 m（+60%） | 22.5 → 9.1 W（−60%） |
| 中速 | 1.59 → 1.33 Hz（−16%） | 0.154 → 0.184 m（+20%） | 35.1 → 21.5 W（−39%） |
| 高速 | 2.27 Hz（不变） | 0.165 m（不变） | — |

三段周期接近等比（$1.20 : 0.75 : 0.44 \approx 1.60 : 1.70$），使低速→中速→高速的过渡平缓；中速选 0.75 而不是更慢的 1.05，是因为后者会把中→高的周期比拉到 2.4 倍，而过渡冲击实测差距不足 1°（在噪声内），不值得为此多担中速段的功率与步幅波动。

高速段为何不能降频：三轴组合（0.51/0.30/0.43）的偏航波动 $\mathrm{p2p}_{\omega_z}$ 随步幅增长，$T\ge0.46$ 即越过 0.05 阈值；在相同步幅下降低占空比（0.46/0.63、0.50/0.58）同样失稳。因此高速段锁定 0.44/0.625。

基线标定条件（影响上述全部数值）：

- 标称足位按整机质心后移 13.3 mm（质心在髂中心后 7.2 mm，默认站立角落足中心在前 6.1 mm），前后腿负载均衡；
- 仿真开启执行器模型：关节电枢惯量 0.01 kg·m²、粘性阻尼 0.1 N·m·s/rad、足端接触 `condim=4`、扭转摩擦 0.03（官方 MJCF/URDF 均未提供，属模型简化）；
- 起步足端混合 0.8 s；以上参数均可用环境变量回退到官方原模型。

## 4. 验收标准

1. 稳态跟踪误差：线速度 ≤ 0.05 m/s，偏航角速度 ≤ 0.05 rad/s。
2. 稳态逐周期均值峰峰值 ≤ 0.05 m/s 或 ≤ 0.05 rad/s，无持续振荡。
3. 无翻倒（倾角 > 25° 或基座高度 < 0.15 m）；建议稳态倾角 < 15°。
4. 单轴全区间、三轴组合、以及跨速度段连续运行（`segments_3x3_20s`）必须全部达标；双轴斜向组合允许保留上述偏航残余，作为闭环验收项。
5. 关节力矩不长时间饱和，支撑足无持续滑移。
6. 段间切换平滑，无速度突变。

稳态窗口：跳过每个运动段前 2 s，取其后不少于 3 个完整步态周期。

## 6. 鲁棒性实测

全部在默认参数、平地（除坡面项）下无头运行，脚本见 `mpc_wbc/test/robustness_closed_loop.py`。

| 扰动 | 做法 | 结果 |
| --- | --- | --- |
| 侧向推力 | 30 N × 0.15 s（±y，机身质心） | 峰值倾角 6.0° / 5.7°，0.50 / 0.66 s 恢复，残余航向 0.0° |
| 侧向推力（加严） | 45 N × 0.15 s | 峰值倾角 8.6°，0.57 s 恢复，残余航向 0.0° |
| 坡面 | 2°（上坡 0.15、上坡 0.30、下坡 0.30） | 3/3 达标，成本 0.105（平地同场景 0.106），最大倾角 1.6° |
| 速度阶跃 | 0.20 ↔ 0.50 m/s，每 3 s 切换，共 10 段 | 10/10 达标，成本 0.174，最大倾角 4.4°，最差 p2p 偏航 0.047 |
| 连续运行 | ±0.30 m/s 各 30 s 交替，共 300 s | 达标；航向漂移 **−0.03°**，倾角均值 0.37–0.44° |

- 45 N × 0.15 s 的横向冲量为 6.75 N·s，约等于机器人以 0.30 m/s 前进时动量的 1.9 倍，仍未翻倒且航向无残余；
- 2° 坡面对关节位置闭环几乎没有影响——开环步态只跟踪机身相对足端轨迹，不补偿坡度，因此上下坡的速度跟踪误差基本不变（最差 0.027 m/s，出现在下坡）；
- 5 分钟长跑没有出现随时间的性能劣化；倾角尖峰集中在 9 次**方向反转**，幅度 1.8–10.3°（均值 4.6°），反转经过低速段时周期被拉长所致，属已记录的瞬态，不是漂移。

## 7. 适用范围（本项目只跑 MuJoCo，不上真机）

**明确前提：本工程的目标是「在 MuJoCo 里把 MPC+WBC 调通并达标」，不做真机部署。**
由此定下几条边界，读数据时要知道：

1. **仿真模型即为基准**。关节电枢惯量 0.01 kg·m²、粘性阻尼 0.1 N·m·s/rad、足端扭转摩擦
   0.03 这些量是让现象接近真实的拟合值（官方 MJCF/URDF 不提供），`SIM_JOINT_ARM`
   /`SIM_JOINT_DAMP`/`SIM_FOOT_CONDIM`/`SIM_FOOT_TORSION` 就是本工程的“真值”，
   不需要再去对齐硬件。
2. **速度偏置补偿已固化**。滑移导致的「机身恒快 0.045 m/s」是模型特性，已标定为
   `cmd_vel_trim = 0.04` 默认值（§5.1 的数字就是默认参数下测的）。
3. **功耗是代理指标**。§3 的功率为关节机械功率 $\sum\lvert\tau\dot q\rvert$ 与铜损代理
   $\sum\tau^2$，不含电机 $K_t$、$R$ 与减速比，只能做方案间横向比较。
4. **未覆盖的扰动**：不平地形、低摩擦地面（$\mu<0.6$）、负载变化、侧向风。
5. **仿真保真度依赖项**：1 kHz 控制回路在真实通信延迟下的表现、编码器噪声、关节温升
   均不在评估范围内。
6. **工程里保留的硬件代码不参与评估**。`interface/` 下的真机驱动/传输脚本、状态机的
   硬件分支都是上游模板遗留，本项目只用 `interface/robot/simulation/mujoco_simulation.py`
   这条路径，不依赖、不保证其余路径可用。
