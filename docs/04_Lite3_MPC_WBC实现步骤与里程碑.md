# Lite3 MPC+WBC 实施步骤与里程碑

> 职责：维护当前阶段、任务依赖和完成条件。指标由 [00](00_设计指标.md) 定义，技术依据由 [09](09_MPC_WBC重新推导与基础契约.md) 定义，实验结果与证据由 [05](05_优化日志.md) 保存。运行命令见 [控制模块 README](../mpc_wbc/README.md)。

## 1. 当前状态

更新日期：2026-10-19。旧 MPC/WBC 与旧求解器已经删除。重建基础阶段 N0–N4 已完成本轮实现及检查；新 MPC/WBC 优化器和闭环运动入口尚未实现。保留的运动学估计器尚未通过新闭环所需的在线接触/滑移复验。

本轮基础检查和单轮开环回归已完成；五轮重复、完整组合/扰动回归及真机验收仍需分别开展。相关实测记录见 [05 的重建基础验证](05_优化日志.md#foundation-validation)。

## 3. 下一批任务

1. 核对球足球心、几何最低点、瞬时材料接触点的速度与加速度定义，建立对应的独立对表；据此决定支撑约束所用的雅可比。
2. 在实际开环运动日志中对照估计速度、高度与仿真真值，分开统计支撑误判、足滑移和缺帧的影响；真值仅用于诊断。
3. 定义接触置信度和估计失效处理，使控制器能区分可信支撑、落地过渡与持续滑移。
4. 建立连续位置/航向参考，明确速度模式、停止锁存、角度展开和重置 epoch；独立验证参考连续性。
5. 冻结 00 中尚未量化的饱和持续时间、滑移、停步收敛和目标跳变门槛，避免后续用主观描述判定通过。

## 4. 后续验收与真机准备

- 基础参数或通信改变后，以同一开环场景复验，并完成规定的重复次数。
- 新 WBC 先做站立与任务/力矩通道验证；接入 MPC 后从低速六方向开始，再扩大到中高、组合、换向、扰动与长跑。
- 记录求解失败、解年龄、实际执行力矩、观测年龄与墙钟周期；实时截止时间及允许缺帧门槛需单独冻结。
- 真机迁移前核对 SDK 控制权、关节映射、IMU/角速度单位、每帧状态一致性、实际力矩限制、急停与保护状态。
- 用实测执行器与足垫参数替换仿真拟合值，开展关节温升、长时间饱和、通信延迟与噪声验证。低摩擦、不平地形、负载变化和其他作用点扰动的覆盖范围另行明确。

## 5. 状态更新规则

完成一项工作后只更新本文的任务状态和证据链接。参数、指标曲线、测试条件、数值结果和失败原因统一写入 05；运行方法统一更新到对应 README；数学或接口定义的变化写入 09。缺少必要证据时，状态记为未完成或待验证。
